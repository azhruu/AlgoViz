                  What’s inside
                  
  
                  
    
                  Sorting
                  Bubble, selection, insertion, merge, quick, heap and more — with bar animations and swap tracking.
                  Live
                  
    
                  Searching
                  Linear and binary search live — watch the scan check each element, or the mid-pointer halve the search window until it finds the target.
                  Live
                  
    
                  Trees
                  Binary search tree, AVL tree and heap are live — insert and search animated on a node canvas, one comparison at a time, with the AVL tree rebalancing itself through LL, RR, LR and RL rotations and the heap bubbling values up and down between a tree view and an array view.
                  Live
                  
    
                  Graphs & Pathfinding
                  BFS, DFS, Dijkstra and A* on an interactive grid.
                  In roadmap
                  
    
                  Linked Lists & Stacks
                  Pointer-level animations for the classic linear structures — a linked list with head, tail and NULL pointers, a doubly linked list you can walk forward from the head or backward from the tail, plus live stack and queue panels.
                  Live
                  
    
                  Hashing
                  Hash functions, collisions and chaining — made visible: keys hash into 8 buckets with h(key) = key mod 8, and keys that collide chain up in the same bucket, with a running collision count and load factor.
                  Live
